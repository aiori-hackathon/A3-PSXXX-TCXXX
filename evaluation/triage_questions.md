# Triage Questions

## S1 (SSH Bruteforce)
1. When did the attacker first successfully log in (UTC)?
2. Which source IP?
3. What was the first privileged command run?
4. How many distinct users were targeted?

## S2 (Web Attack)
1. When did the first attack request occur (UTC)?
2. Which source IP?
3. What sensitive file was read via path traversal?
4. What was the name of the uploaded webshell?

## S3 (Clock Skew)
1. When did the attacker first successfully log in (UTC)?
2. Which source IP?
3. What was the first privileged command run?
4. Which happened first: web01 webshell or db01 login?
